# lumawen-pickups

Open-source hexaphonic guitar pickups: one signal per string, for MIDI, per-string effects and smarter learning tools.

## Status

Early design. Nothing here is ready to build yet. Watch the repo or join the Discord to follow along.

## What's here

- `docs/`: how the pickups work and how to build them
- `hardware/`: schematics, PCB files and coil specs
- `test/`: measurement notes and recordings
